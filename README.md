# 🌻 Galaxia de Flores Amarillas

Una experiencia web interactiva creada para celebrar el **Día de las Flores Amarillas**.  
El proyecto combina una galaxia animada, flores amarillas, mensajes personalizados, fotografías y música para crear una pequeña experiencia visual e interactiva.

Al iniciar, el usuario entra en un universo espacial donde puede explorar la galaxia, descubrir flores y visualizar diferentes mensajes y recuerdos.

---

## ✨ Características

- 🌌 Galaxia interactiva creada con **Three.js**.
- 🌻 Flores amarillas generadas mediante código.
- ✨ Efectos de brillo, partículas y animaciones.
- 💛 Mensajes personalizados dentro de la experiencia.
- 📸 Integración de fotografías.
- 🎵 Música de fondo.
- 🖱️ Interacción mediante mouse y pantalla táctil.
- 📱 Diseño responsive para computadoras, tablets y celulares.
- 🌙 Pantalla de inicio con temática espacial conectada visualmente con la galaxia.
- ⚡ Proyecto completamente frontend, sin necesidad de servidor backend.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** — estructura de la aplicación.
- **CSS3** — diseño, animaciones y efectos visuales.
- **JavaScript** — lógica e interactividad.
- **Three.js** — renderizado y creación de la galaxia 3D.
- **Canvas API** — generación de elementos visuales como las flores.
- **Git / GitHub** — control de versiones y almacenamiento del proyecto.
